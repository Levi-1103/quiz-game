
# Quiz-Game

Kahoot Clone built with Golang and SvelteKit

## Features - (in development)

- Real-Time Gameplay – Fast, interactive quizzes using WebSockets
- Host & Player Roles – Hosts control games; players join via PIN
- Quiz Builder – Create and manage custom quizzes with timers and choices
- Live Leaderboard – Scores update in real-time based on speed and accuracy
- SvelteKit Frontend – Responsive, reactive UI for all devices
- Golang Backend – High-performance REST & WebSocket server
- MongoDB Storage – Persistent quiz and session data
- Secure Sessions – Unique game PINs and controlled access

## Tech Stack

**Client:** SvelteKit, TailwindCSS, SkeletonUI

**Server:** Golang, Fiber, MongoDB, Docker
